# assets/ — 게임에 쓰는 스프라이트

이 폴더의 그림은 전부 **신규 창작**이다. 원작(SNK 메탈슬러그)에서 추출한
스프라이트는 한 장도 들어 있지 않다. `docs/ART_PROMPTS.md` 의 프롬프트로
이미지 생성 모델에서 뽑은 뒤 `tools/art_import.py` 로 정리했다.

각 항목은 두 가지 형태로 들어 있다.

- `<이름>.png` — 프레임을 가로로 이어 붙인 아틀라스. 엔진이 이걸 하나만 올리고
  좌표로 잘라 쓴다
- `<이름>/<이름>_00.png …` — 낱장 프레임. 눈으로 확인하거나 개별 수정할 때 쓴다

`sprites.json` 에 항목별 프레임 수와 칸 크기(cell_w, cell_h)가 들어 있다.
모든 캐릭터는 높이 128px, 발바닥이 칸 아래쪽에 맞춰져 있다.

다시 만들거나 추가할 때:

    python3 tools/art_import.py <생성한_PNG_폴더> --out assets
