# Release 0.3.1 — Pure Original Edition (그래픽 향상만 적용)

## 1. 원인 / 변경 요약
- 오리지널 버전에서 본연의 게임성을 해치지 않도록 **각도 선택(`0°~90°`), 자동 락온(`ms_find_aim_target`), 십자 과녁(`drawSubtleAutoReticle:`), 각도 배지 UI를 전부 삭제**.
- 원작 방식(정면 사격 + `Up` 키 상단 사격) 그대로 유지하면서 **그래픽 향상**(다층 사막 노을 배경, `100%`/`150%`/`200%` 스케일, 리마스터 티어 1x/2x, 황금 예광탄, 3m 고시인성 HUD)만 적용.

## 2. 되돌리는 법
- 프레임 저하 시 `R` 키로 해상도를 `100%`로 낮추거나, 이전 릴리즈 `.ipa`를 TrollStore로 덮어쓰기 설치.

## 3. 기기에서 볼 것
1. 화면에 각도 배지·십자 과녁·점선 등 추가 UI가 일절 없고 순수 아케이드 화면만 보이는지 확인.
2. 정면 사격 및 `Up` 키 상단 사격이 원작 감각 그대로 작동하는지 확인.
3. `R` 키로 `100%`/`150%`/`200%` 해상도 전환과 재실행 후 `NSUserDefaults` 복원 확인.
